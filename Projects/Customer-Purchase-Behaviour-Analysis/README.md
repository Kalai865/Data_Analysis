# Customer Purchase Behaviour Analysis

## Project Overview

This project explores customer purchasing patterns using Python
and data analysis and visualization libraries.

## Objective

To analyse customer spending behaviour based on demographic,
geographical, occupational and product-related factors.

## Tools & Libraries

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn

## Analysis

- Gender-wise customer analysis
- Gender-wise spending analysis
- Age-group analysis
- State-wise sales analysis
- Occupation-wise sales analysis
- Product-category analysis
- Marital-status analysis

## Skills Demonstrated

- Data Cleaning
- Data Exploration
- Data Manipulation
- GroupBy and Aggregation
- Data Visualization
- Exploratory Data Analysis
- Insight Generation
