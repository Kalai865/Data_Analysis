# Student Performance Analysis

## Overview

This project explores student performance data to understand how different student and family-related factors are associated with academic performance.

The analysis focuses on Math, Reading, and Writing scores and uses Python data analysis and visualization libraries to explore patterns within the dataset.

## Objective

The main objective of this project is to analyze student performance and explore relationships between academic scores and factors such as:

- Ethnic Group
- Parent Education
- Lunch Type
- Test Preparation
- Parent Marital Status
- Sports Practice
- First Child Status
- Number of Siblings
- Transportation Mode
- Weekly Study Hours

## Tools & Libraries

- **Python**
- **NumPy** – Numerical operations
- **Pandas** – Data loading, manipulation, grouping, and analysis
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization and heatmaps

## Analysis Performed

The project includes analysis of student performance based on:

- Ethnic group
- Parent education level
- Lunch type
- Test preparation
- Parent marital status
- Sports practice
- First-child status
- Number of siblings
- Transportation mode
- Weekly study hours

The analysis uses **Pandas pivot tables** and **Seaborn heatmaps** to compare student performance across different factors.
